# Documentacao do projeto

Este diretorio guarda os guias internos do mmcriativos. Todo novo modulo deve chegar com atualizacao aqui para manter o onboarding simples.

## Como navegar
- `getting-started/requirements.md` - sistemas, extensoes e dependencias obrigatorias.
- `getting-started/local-development.md` - passo a passo para subir o ambiente local.
- `architecture/overview.md` - visao geral de camadas, fluxo HTTP e padroes usados.
- `domain/projects-and-tasks.md` - processos do modulo de projetos e tarefas.
- `domain/budgets-and-commercial.md` - funil comercial, planos, orcamentos e pagamentos.
- `domain/public-briefing.md` - formularios publicos de briefing/percepcao.
- `operations/deployment.md` - checklist de deploy e configuracoes de producao.
- `operations/runtime.md` - rotinas de operacao continua (fila, logs, agendamentos).
- `glossary.md` - definicao dos termos de negocio usados em todo o produto.

## Convencoes
- Escreva em portugues claro utilizando ASCII.
- Referencie arquivos/linhas sempre que precisar apontar comportamento especifico.
- Prefira topicos curtos e links relativos (`../`) ao citar outros documentos.
